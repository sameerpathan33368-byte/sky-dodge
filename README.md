## 📌 About the Project

Sky Dodge is an interactive web game designed and developed independently from concept to deployment.

The project focuses on building an engaging browser experience while practicing modern web development, game logic, user interaction, and application deployment.

## ✨ Features

- Interactive browser-based gameplay
- Player controls and game interaction
- Dynamic game mechanics
- Score-based gameplay
- Responsive user interface
- Browser-based execution without installation
- Publicly deployed live version

## 🛠️ Technologies Used
